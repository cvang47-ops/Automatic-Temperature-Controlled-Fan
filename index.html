01 · PROJECT OVERVIEW

What am I building?

The goal is to make a fan that responds to temperature instead of requiring a person to switch it on and adjust it manually.

A temperature sensor measures the surrounding air and sends a signal to the Arduino Uno. The Arduino processes the reading using a control algorithm. It then sends a PWM signal to a motor driver, which controls a DC motor connected to a fan blade. As the measured temperature rises, the fan is programmed to run faster.

04 · PROGRAMMING

Control algorithm

The Arduino will average multiple sensor readings to reduce small fluctuations, convert the reading into temperature, and select a fan command based on temperature ranges. The initial plan uses four fan states:

TemperatureFan settingExample PWM
Below 25°COff0
25–29°CLow100
30–34°CMedium170
35°C or higherHigh255

PWM values are initial commands, not guaranteed motor speeds. The minimum duty cycle required to start a motor depends on the motor and driver.

Starter code — LM35 sensor example

/*
  Project: Automatic Temperature-Controlled Fan
  Board: Arduino Uno
  Sensor: LM35 (confirm sensor model before use)
  Actuator: DC fan through a suitable motor driver

  AI assistance: ChatGPT (OpenAI)
  Code and control logic adapted with AI assistance.
*/

const int sensorPin = A0;
const int fanPin = 9;

void setup() {
  pinMode(fanPin, OUTPUT);
  Serial.begin(9600);
  analogWrite(fanPin, 0);
}

void loop() {
  // Average 10 readings to reduce measurement noise
  long total = 0;
  for (int i = 0; i < 10; i++) {
    total += analogRead(sensorPin);
    delay(10);
  }

  float reading = total / 10.0;
  float voltage = reading * (5.0 / 1023.0);

  // LM35 output is approximately 10 mV per degree C
  float temperatureC = voltage * 100.0;

  int fanSpeed;
  if (temperatureC < 25) {
    fanSpeed = 0;
  } else if (temperatureC < 30) {
    fanSpeed = 100;
  } else if (temperatureC < 35) {
    fanSpeed = 170;
  } else {
    fanSpeed = 255;
  }

  analogWrite(fanPin, fanSpeed);

  Serial.print("Temperature: ");
  Serial.print(temperatureC);
  Serial.print(" C | Fan PWM: ");
  Serial.println(fanSpeed);

  delay(500);
}
Important: This conversion assumes an LM35 and a 5V analog reference. A TMP36, DHT11, DHT22, or another sensor needs different wiring and/or code. Confirm the sensor model before uploading this program.

06 · RESEARCH & MOTIVATION

Similar projects and real-world use

Temperature-controlled fans are used to cool electronics, enclosures, computers, and indoor spaces. Similar hobby projects commonly use a temperature sensor, a microcontroller, and a transistor or motor driver to switch or vary a fan. Commercial fan controllers may add a dedicated thermal probe, display, multiple fan outputs, and more adjustable settings.

My design is intended as a simple educational prototype. Instead of using a finished controller, I will write and test my own Arduino control algorithm so I can understand how sensor readings become physical actions.

Why I chose this project

I chose this project because it is practical, achievable with an Arduino kit, and gives me a chance to connect programming with a physical mechanical output. I want to improve my skills with sensors, motor control, PWM, circuit wiring, and troubleshooting. Someone could use a system like this when automatic cooling is useful and manual fan adjustment is inconvenient.
